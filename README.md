# MiranteContabil

Este progeto foi gerado pelo angular[cli] com a versão 22.1.8.

## Inicialização

para dar start na aplicação é necessário instalar as dependências da aplicação com o comando

```bash
npm install
```

depois inicializar a aplicação

```bash
ng serve
```

e após isso é necessário inicializar o json-server para simular o backend da aplicação
```bash
npx json-server db.json
```

o projeto foi totalmente desenvolvido em angular com a versão 22.1.8. e utilizando

Angular Material -v 22.1.6
Bootstrap -v 5.3.8
json-server -v 1.0.0-beta.15


Angular CLI does not come with an end-to-end testing framework by default. You can choose one that suits your needs.
